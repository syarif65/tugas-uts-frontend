
# 🌱 AgriManage
### Sistem Manajemen Data Lahan dan Tanaman

AgriManage merupakan aplikasi berbasis web yang dirancang untuk membantu pengguna dalam mengelola data lahan pertanian dan tanaman secara sederhana, terstruktur, dan efisien.

Proyek ini dikembangkan sebagai implementasi pembelajaran pemrograman frontend menggunakan HTML, CSS, dan JavaScript.

---

## 📌 Fitur Utama

- **Dashboard** — Menampilkan ringkasan total lahan, tanaman, luas lahan, dan tanaman siap panen.
- **Data Lahan** — Mengelola informasi nama lahan, lokasi, luas, dan kondisi lahan.
- **Data Tanaman** — Mengelola jenis tanaman, lokasi lahan, tanggal tanam, dan status tanaman.
- **Data Panen** — Menampilkan tanaman yang siap dipanen.
- **Tambah Data** — Menambahkan data lahan dan tanaman baru.
- **Edit Data** — Memperbarui informasi yang sudah tersimpan.
- **Hapus Data** — Menghapus data yang tidak diperlukan.
- **Pencarian** — Mencari data berdasarkan nama atau lokasi.
- **Penyimpanan Lokal** — Menyimpan data menggunakan localStorage browser.
- **Responsive Design** — Tampilan menyesuaikan ukuran layar perangkat.

## 🚀 Cara Menjalankan Proyek

### 1. Persiapan

Pastikan sudah menginstal:
- Visual Studio Code
- Browser seperti Google Chrome
- Extension Live Server pada Visual Studio Code

### 2. Membuka Proyek

1. Buka Visual Studio Code.
2. Pilih **File → Open Folder**.
3. Pilih folder `agrimanage`.
4. Pastikan semua file proyek tersedia.

### 3. Menjalankan Website

1. Buka file `index.html`.
2. Klik kanan pada editor.
3. Pilih **Open with Live Server**.
4. Website akan terbuka secara otomatis di browser.

---

## 💾 Penyimpanan Data

AgriManage menggunakan `localStorage` untuk menyimpan data lahan dan tanaman.

Data disimpan pada browser yang digunakan sehingga tetap tersedia ketika halaman dimuat ulang.

**Catatan:** Data belum menggunakan database MySQL dan belum dapat disinkronkan antarperangkat.
